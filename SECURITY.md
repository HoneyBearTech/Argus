# Security Policy

## Reporting a vulnerability

Please report vulnerabilities in Argus through GitHub's private vulnerability
reporting form:

https://github.com/HoneyBearTech/Argus/security/advisories/new

Do not report vulnerabilities through public issues. Include the affected
version or commit and enough detail to reproduce the issue. Please avoid
accessing or changing data that is not yours while investigating.

## Coordinated disclosure

We aim to acknowledge reports within 7 days and will work with the reporter to
investigate and address the vulnerability. Please allow up to 90 days for a
fix and coordinated disclosure. We ask that details remain private until a fix
is available or 90 days have passed, whichever comes first.
